Pick which cameras each computer records. After a camera starts, mark its monitors on Calibrate so the numbers get read.

Record from the computer you're using now

Nothing to install: open this page on the computer next to the monitors, pick its webcam and press Start. For long unattended tests, the capture program (below) is the sturdier choice: it keeps running without a browser window.

The capture program runs on the computer the webcam is plugged into and keeps recording without a browser window. Install it as described in agent/README.md, pointing it at this website. Or, on your own computer, double-click start-demo in the project folder to try everything locally.
