What's different in this preview

  • Nothing you change is saved: there is no server behind this preview, only recorded answers.
  • Some screens repeat the recorded moments instead of updating forever.
  • Downloads (CSV, images) and printing only work on the real platform.
  • The recorder can't use your real webcam here. To try your webcam, run the platform on your computer or server (below).

Get the real thing

On your computer (try your webcam)

  1. Install Python 3.12 from python.org.
  2. Download the project ZIP from GitHub (branch claude/aq-capture-platform) and unzip it.
  3. Double-click start-demo.bat (Windows) or start-demo.command (Mac).
  4. The Cameras page opens: pick your webcam and press Start recording.

As a website on your Hostinger server

  1. Open hPanel → VPS → Browser terminal.
  2. Clone the project, then run cd aq/deploy && bash setup.sh.
  3. Press Enter for a free temporary address, or type your own subdomain.
  4. Open the printed address and log in. Details: docs/deploy.md.
